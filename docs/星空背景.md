# 星空背景

## 改了什么

原来首页顶部是**纯色兜底**：`#page-header { background-color: #a06bff }` 加上一层蒙版，
看起来就是一块纯紫（截图实测 `#704BB2` = `#A06BFF` × 0.7）。

现在换成了星空图。

## 配置（`_config.butterfly.yml`）

```yaml
default_top_img: /img/starry-sky.jpg   # 其他页面的顶部图
index_img: /img/starry-sky.jpg         # 首页的顶部图
```

生效范围：

| 页面 | banner |
| --- | --- |
| 首页 / 归档 / 标签 / 分类 / 友链 / 留言板 / 关于 | 星空 |
| 文章页 | 各自的封面（本来就有，不动） |

## 图片规格

`source/img/starry-sky.jpg` —— 2400×1350、189 KB

生成方式（PIL，随机种子固定，可复现）：

1. **底色**：紫黑 → 靛蓝的纵向渐变
2. **星云**：4 团高斯模糊的紫/蓝色团，**故意避开画面正中**——标题就在那儿，
   背景太亮会糊住文字
3. **银河带**：一条斜向柔光，带内的星星密度更高
4. **星星**：三层共约 4600 颗（3600 微星 + 900 中星 + 140 亮星），
   尺寸和亮度都服从随机分布，颜色在白/蓝白/暖白/淡紫间变化
5. **亮星**：34 颗带光晕和十字光芒
6. 2 倍超采样绘制后 LANCZOS 缩小，边缘更干净

### 为什么用 JPEG 不用 PNG

星点是高频细节，PNG 压不动：同样画质 **PNG 651 KB vs JPEG 189 KB**。

质量选 q88：实测亮星像素保留 **99.7%**，且背景无明显压缩噪点。

### 蒙版调整

`--mark-bg` 是压在 banner 图上的那层蒙版，主题默认 `rgba(0,0,0,.3)`。

> ⚠️ 上一轮做紫色主题时，我把暗色模式的 `--mark-bg` 设成了 `rgba(160,107,255,.26)`。
> 这在纯色背景下没问题，但**换成星空后会出事**：那是一层亮紫色，
> 会把暗色星空冲淡成紫色，星星全看不见了。
> 现已统一改为 `rgba(8, 5, 16, .32)`——带一点紫调的深色，压暗但保留星点。

## 验证过的数据

| 指标 | 数值 |
| --- | --- |
| 全图平均亮度 | 28.4 / 255（足够暗，是夜空该有的样子） |
| 亮星像素占比 | 1.05% |
| 标题白字对比度 | **18.3:1**（WCAG AA 只需 4.5:1） |
| 手机竖屏可见区（中间 26% 竖条）亮星占比 | 0.98%（和全图基本一致） |

最后一条特意验过：手机竖屏用 `cover` 只会显示图片中间 26% 的竖条，
如果星星只铺在四周，手机上就会看到一片空白。现在星星是均匀分布的，不会出现这个问题。

## 想换成别的

把 `index_img` / `default_top_img` 换成别的图片路径即可（图片放 `source/img/`）。

想用网络图片就直接填完整 URL。

不想要了就把这两行留空，会退回纯色兜底。
