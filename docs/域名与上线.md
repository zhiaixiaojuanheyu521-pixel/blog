`.top` 首年 ¥14 是新人价，**续费大约 ¥40~50/年**。
建议现在就去阿里云开「自动续费」或设个日历提醒（提前 1 个月）。
域名过期被别人抢注后想买回来，通常要几千块。

## 已完成的博客配置

```yaml
# _config.yml
url: https://yuu-blog.top
pretty_urls:
  trailing_index: false   # 去掉 URL 末尾的 index.html
  trailing_html: false
```

`trailing_index: false` 让 canonical 从
`https://yuu-blog.top/index.html` 变成 `https://yuu-blog.top/`，
避免搜索引擎把同一页面当成两个。

## 待办：把网站放上线

域名只是门牌号，**网站本身还需要一个「家」**。两条件：

### 路线 A：Cloudflare Pages（免费，不用备案）⭐ 推荐

```
① 把 ~/blog 推到 GitHub 仓库
② Cloudflare Pages 连仓库
     构建命令: npx hexo generate
     输出目录: public
③ 拿到 xxx.pages.dev，先确认能打开
④ Cloudflare 添加站点 yuu-blog.top → 得到两个 NS 地址
⑤ 回阿里云改 NS：
     控制台 → 域名 → 管理 → DNS修改 → 修改DNS服务器
     把 dns13/dns14.hichina.com 换成 Cloudflare 给的两个
⑥ Cloudflare Pages → 自定义域 → 绑定 yuu-blog.top
```

要点：
- **Cloudflare Pages 必须改 NS**，因为它的自定义域名要求域名托管在 Cloudflare
- 改完 NS，阿里云的解析就失效了，以后解析都在 Cloudflare 控制台改
- HTTPS 自动配好，不用管证书

### 路线 B：自己的服务器（VPS）

阿里云云解析加两条记录即可，不用改 NS：

| 记录类型 | 主机记录 | 记录值 |
| --- | --- | --- |
| `A` | `@` | 服务器公网 IP |
| `A` | `www` | 服务器公网 IP |

服务器上用 nginx 指到 `public/` 目录，配置见 `deploy.sh` 的注释。

⚠️ 服务器在**中国大陆**就必须 ICP 备案（1~3 周），香港/国外则不用。

### 路线 C：GitHub Pages（免费）

阿里云云解析加：

| 记录类型 | 主机记录 | 记录值 |
| --- | --- | --- |
| `A` | `@` | `185.199.108.153` |
| `A` | `@` | `185.199.109.153` |
| `A` | `@` | `185.199.110.153` |
| `A` | `@` | `185.199.111.153` |
| `CNAME` | `www` | `你的用户名.github.io` |

（这 4 个是 GitHub Pages 官方 IP）
然后在 `source/` 下建一个 `CNAME` 文件，内容就一行 `yuu-blog.top`。

⚠️ GitHub Pages 在国内访问不稳定，时通时断。

## 上线后建议

- 提交 sitemap 到搜索引擎（需要装 `hexo-generator-sitemap` 和 `hexo-generator-feed`）
- 中文标题的文章 URL 会被 percent-encode 成 `%E4%BD%A0%E5%A5%BD...`，
  分享出去很难看。想解决可以装 `hexo-abbrlink` 生成短链
